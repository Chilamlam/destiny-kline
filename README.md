# 命运K线 (Destiny K-Line) · 人生流年运势量化推演系统 📈☯️

> **将中国传统生辰八字、流年大运与现代金融量化K线交易图表完美融合的玄学娱乐 Web 应用**。
> 用户输入出生年月日时（支持公历/农历），系统自动排盘八字命局、推演起运流年，并将其量化为自出生至今直至未来的**人生命运K线走势图**。

---

## 🌟 核心特色与功能复刻

### 1. 经典古风证券界面美学（高度复刻原图）
- **宣纸典雅质感**：米黄宣纸底色、古籍卷轴式章节标题（`卷一 运势总览`）、朱砂红印章印鉴。
- **古典横向章节导航**：
  - `运势总览`：核心命运K线全景图
  - `盘势要诀`：四柱八字、藏干十神、五行雷达分布与身旺身弱格局
  - `未来推演`：未来15年黄金高光岁运与潜伏蛰伏期的前瞻分析
  - `分部细览`：财富、事业、感情、健康四维独立量化走势对照
  - `命盘喜忌`：喜用神方位、贵人时令、吉祥色与行业指引
  - `大事年谱`：编年史列表，快速检索重大年份事象与吉凶神煞

### 2. 命运量化K线引擎
- **全生命周期覆盖**：从 0 岁出生年排至 85 岁以上，包含过去与未来。
- **今·时间分水岭**：精准划分历史实盘与未来推演（以当前年份为界，右侧呈现空心虚框推演K线）。
- **专业五维切换**：一键切换 **综合、财富、事业、感情、健康** 五大独立维度。
- **下钻式月K（逐月分析）**：点击年K中任意一根蜡烛，直接钻入该年度 12 个流月的月K细览，支持双击/一键返回。
- **丰富技术指标**：
  - `一年线`（平滑大运趋势均线）
  - `命理原判`（金色虚线生命周期基准）
  - `事件量`（Volume 柱状图，反映当年/当月波动激烈程度与变动能量）
  - `神煞标记`：▲ 吉事、▼ 凶事、◆ 转折点、以及大运交接与岁运并临

### 3. 一键生成并导出宣纸长图海报
- 支持生成精美古典印记的长图海报，内置命主八字、日元格局、流年批语与运势指数，方便访客在微信、小红书、朋友圈等社交媒体分享炫耀。

## 🚀 本地运行与开发

本应用采用轻量纯前端架构（React 18 + TypeScript + Vite + TailwindCSS + ECharts + lunar-javascript），无需繁重后端数据库，即开即用。

```bash
# 1. 进入项目根目录
cd destiny-kline

# 2. 启动本地开发服务
npm run dev

# 3. 本地预览生产构建
npm run preview
```

访问浏览器：`http://localhost:4173/` 或 `http://localhost:5173/`

## 🌐 怎样放到个人网站上？

你可以根据自己的网站架构选择最适合的部署方式：

### 方案 A：一键打包为纯静态资源直接上传 (推荐)
运行构建命令：
```bash
npm run build
```
构建完成后会生成 `dist/` 文件夹。所有资源均为相对路径，你可以：
1. **直接拷贝到现有的网站子目录**：例如将 `dist` 重命名为 `destiny` 放到你的 WordPress、Nginx 或 Apache 根目录下，访问 `https://yourdomain.com/destiny/` 即可。
2. **部署到免费的静态托管服务**：直接将代码上传至 GitHub Pages、Vercel、Cloudflare Pages 或 Netlify，获得一个独立的免费二级域名。

### 方案 B：使用 `iframe` 嵌入任意个人博客页面
如果你已经有 Hexo、Hugo、VuePress 或 WordPress 文章/页面，只需在你的 Markdown 或 HTML 中加入一行：
```html
<iframe 
  src="https://yourdomain.com/destiny/" 
  style="width: 100%; height: 850px; border: none; border-radius: 8px; box-shadow: 0 4px 16px rgba(0,0,0,0.06);"
  title="命运K线"
></iframe>
```

## 📜 命理量化算法原理解析

1. **生辰八字排盘**：依托经典算法库精确计算农历二十四节气换月干支，确定年柱、月柱、日柱、时柱。
2. **五行衰旺与喜用神**：根据月令得令、印比通根透干评分，推导日元强弱（身强、身弱、专旺、从格、中和），智能得出守护喜用神与相克忌神。
3. **大运与流年互动模型**：
   - 按照阳男阴女顺行、阴男阳女逆行排出十年大运。
   - 每年流年干支与大运干支、日主原局发生生克制化、地支六冲（如子午相冲）、六合、三合局等交互。
   - 转化为开盘（Open）、最高（High）、最低（Low）、收盘（Close）四维金融K线数据。
